1. HARDWARE & SENSOR TELEMETRY FILES
--------------------------------------------------------------------------------

[ ] FILE 1: sim_bme280_breath_telemetry.csv
    Priority: P0 (Critical)
    Purpose: Directly addresses the Mentor's BME280 breath sensor proposal (DFKI 
             study, 96% accuracy in face-mask settings, minute ventilation 
             refinement, respiratory rate tracking).
    Target Folder: simulation/
    Suggested Columns:
      - timestamp                      : ISO8601 timestamp (e.g. 2025-05-10T11:30:00)
      - worker_id                      : Worker identifier (e.g. SIM-001)
      - temperature_c                  : BME280 sensor temperature inside mask (°C)
      - relative_humidity_pct          : BME280 humidity inside mask (%)
      - pressure_hpa                   : Atmospheric pressure inside mask (hPa)
      - respiratory_rate_bpm           : Calculated breaths per minute
      - mask_donned_flag               : Boolean (True if mask is worn properly)
      - minute_ventilation_est_l_min   : Estimated volume of air inhaled (L/min)
      - condensation_clog_flag         : Sensor moisture saturation indicator

[ ] FILE 2: sim_rfid_qr_checkin_logs.csv
    Priority: P1 (High)
    Purpose: Backs up the Work Hours (55+ hrs over 4 weeks) and Combined Workload 
             parameters from the image table. Current simulation lacks raw 
             time-stamped tap events.
    Target Folder: simulation/
    Suggested Columns:
      - log_id                         : Unique transaction identifier
      - worker_id                      : Worker identifier
      - node_id                        : Hardware ESP32 node identifier
      - site_id                        : Worksite location ID (e.g. bhuj, kandla_port)
      - timestamp                      : Scan timestamp
      - event_type                     : CHECK_IN / CHECK_OUT
      - scan_method                    : RFID_CARD / QR_CODE / PROVISIONAL_MANUAL
      - weekly_accumulated_hours       : Rolling 7-day total hours worked
      - consecutive_weeks_over_55      : Count of consecutive weeks >= 55 hours

[ ] FILE 3: sensor_calibration_curves.csv
    Priority: P2 (Medium)
    Purpose: Mathematical transfer functions and reference instruments for the 
             hardware parts specified in the project image.
    Target Folder: tables/
    Suggested Columns:
      - sensor_part                    : INMP441 / GUVA-S12SD / TCS34725 / BME280
      - parameter_tracked              : Noise dose / UV dose / Hydration / Respiration
      - raw_unit                       : ADC_RMS_COUNTS / MILLIVOLTS / RGB_CLEAR_LUX
      - physical_unit                  : dBA / UV_INDEX_SED / ARMSTRONG_URINE_SCALE_1_8
      - transfer_formula               : Calibration function or lookup equation
      - reference_instrument           : Type 2 Sound Meter / Spectroradiometer / Colorimeter
      - error_tolerance_pct            : Expected prototype margin of error

2. CLINICAL & MEDICAL DIAGNOSTIC FILES
--------------------------------------------------------------------------------

[ ] FILE 4: sim_clinical_test_records.csv
    Priority: P0 (Critical)
    Purpose: Provides actual medical numbers for clinic screens so that 
             "doctors decide what the tests mean". Currently, README.md notes 
             no clinical test values are generated.
    Target Folder: simulation/
    Suggested Columns:
      - test_id                        : Unique medical examination ID
      - worker_id                      : Worker identifier
      - screening_date                 : Date of clinical visit
      - facility_id                    : Facility where check-up occurred
      - doctor_registration_no         : Examining physician / surgeon ID
      - fev1_litres                    : Forced Expiratory Volume in 1 second
      - fvc_litres                     : Forced Vital Capacity
      - fev1_fvc_ratio                 : Ratio indicating obstructive/restrictive defect
      - fev1_pct_predicted             : % of age/height predicted normal value
      - cxr_ilo_profusion              : ILO classification category (e.g. 0/0, 1/1, 2/1)
      - cxr_opacities_shape            : Round (p, q, r) or irregular (s, t, u)
      - serum_creatinine_mg_dl         : Lab blood creatinine (kidney check)
      - egfr_ckd_epi                   : Estimated GFR (mL/min/1.73m²)
      - urine_specific_gravity         : Hydration status indicator
      - urine_protein_dipstick         : Proteinuria indicator (NIL / TRACE / 1+ / 2+)
      - spo2_pct                       : Pulse oximetry oxygen saturation (%)
      - resting_pulse_bpm              : Pulse rate (beats/min)
      - systolic_bp_mmhg               : Systolic blood pressure (for long-hours trigger)
      - diastolic_bp_mmhg              : Diastolic blood pressure
      - pta_hearing_threshold_db_4khz  : Pure Tone Audiometry hearing threshold at 4 kHz
      - sputum_cbnaat_result           : TB test result (NEGATIVE / POSITIVE / NOT_TESTED)
      - clinical_verdict               : NORMAL / SUSPECTED_SILICOSIS / CKD_RISK / HYPERTENSION
      - fitness_certificate_status     : FIT / FIT_WITH_RESTRICTION / TEMPORARILY_UNFIT
